# 🌸 Pollinations Text Generator

A browser-based writing assistant powered by the [Pollinations.ai](https://pollinations.ai) text API.

## Features

- 🔑 Secure API key storage (locally obfuscated)
- ✍️ Multiple AI models: OpenAI GPT-4o, Claude, Gemini, Mistral, LLaMA
- 📏 Target word count injected into the prompt
- 🎭 Custom writing tone (formal, casual, poetic, etc.)
- 📋 Copy to clipboard
- ⬇️ Download as .txt file

## Getting Started

1. Get your API key at [enter.pollinations.ai](https://enter.pollinations.ai)
2. Open `index.html` in your browser
3. Enter your API key — stored locally, never shared
4. Write a prompt, choose settings, generate!
